# 上传动线维护 · 2026-11-08

选图、处理和复制保持一条连续流程。桌面队列与设置并排，窄屏选项折叠在队列前；主操作是保留构图的压缩上传，逐张裁剪独立保留。全部成功后手机底栏切换为复制全部链接。

每张结果新增复制图片网址，批量格式也支持纯 URL。Markdown、HTML、Hugo figure、裁剪比例、旋转、排序、重试、取消、命名和冲突保护均保留。

`list-view.js` 按图片 ID 和实际影响渲染的字段复用 DOM，避免输入设置和其他图片的状态变化重建整列缩略图。排序和新项只播放短暂动画，静止时无动画循环。减少动态效果偏好仍有效。

顺带修复：压缩后再次检查取消标志；旧裁剪会话的异步完成不能影响新会话；重试采用当前明确选择的冲突策略；清空队列清理旧结果；快速重复复制后正确恢复按钮文案。

## 验证

- TypeScript 和全部前端 JavaScript 语法检查通过。
- API 原有鉴权、Origin、路径检查、改名、取消、覆盖测试通过，服务端源码未改动。
- 本地浏览器使用合成图片，执行真实 Canvas/WebP 编码；上传 API 和公开测试图片响应被拦截，不写入真实 R2。
- 批量成功、重复文件过滤、排序、单张失败继续、单张重试、纯 URL / Markdown / 批量复制通过。
- 压缩中取消产生零上传；裁剪中取消后立即重试，旧结果不会关闭或改写新会话。
- 覆盖确认后失败，切换为自动改名再重试，实际请求采用 `rename`。
- 桌面和模拟手机裁剪、3:2 比例、旋转、确认、取消以及对象释放通过。
- 360、390、768、1024、1440px 无横向溢出；窄屏操作栏和选项折叠正常。
- 已展开详情在无关设置变化时保留，停止操作后运行中的动画数为零。

手机验证是浏览器视口/触屏模拟，不代表真实 iOS/Android 实机测试。现有 Cloudflare 鉴权、R2 binding 与 API 契约沿用；没有新增数据库或运行依赖。
